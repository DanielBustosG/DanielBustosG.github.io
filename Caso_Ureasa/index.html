Caso de estudio

Confusión por procedencia en inhibidores de ureasa

  • Material de apoyo para: BGM324 · Bioinformática
  • Requisitos: un curso de programación y estadística básica

Seis notebooks que desarman un estudio publicado y lo reconstruyen con sus propios datos. No se asume formación previa en quimioinformática ni en machine learning: ambas se enseñan desde cero sobre los datos del paper.

El paper

Farías-Abarca J, Urra G, Henríquez C, Yáñez O, Osorio MI, Palma J, Morales-Quintana L, Suardíaz R, Bustos D. Provenance-Associated Confounding in Cross-Collection Comparisons of Urease Inhibitors: A Quantified Reference Scale and a Domain-Aware Alternative. Int J Mol Sci. 2026;27(20):9159.

Usa Runtime → Run all, y File → Save a copy in Drive para guardar tus cambios. Léelos en orden la primera vez; después cada notebook sirve como referencia independiente. Están escritos en inglés.
