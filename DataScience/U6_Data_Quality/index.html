A dataset is not a fact; it is the output of a process, and every decision in that process is a choice you must be able to defend. This unit takes the raw ROCK1 download of Units 4 and 5 through a documented curation protocol written as tested code, in which every excluded record carries a reason code and the exclusion counts are reproduced exactly against a reference implementation. It then asks the three questions that decide whether the resulting table can support a model at all: how much experimental noise does it contain, how arbitrary are the class labels we are about to impose, and how concentrated is the data in a few chemical series and a few papers. The last section leaves chemistry for the legal and ethical obligations that attach to human-derived data, and the unit ends with a data card — the document that travels with the dataset.

1. What "quality" means for a dataset

A dataset has no intrinsic quality; it has fitness for a stated purpose. The ROCK1 table is fit to answer "which chemical series were explored against this kinase and how potent were they?" It is much less fit to answer "what is the potency of an arbitrary new molecule?", and the gap between those two statements is what this unit measures.

Four separate things are usually bundled under "data quality", and they need separate treatment.

  1. Correctness. Are the records right? Structures mis-drawn, exponents mis-typed, units mis-read. Audits of public chemistry databases consistently find error rates of a few per cent, concentrated in exactly these places.[6][7][8]
  2. Precision. How reproducible is a correct measurement? This is the experimental uncertainty of Section 4, and it is a hard ceiling on what any model can achieve.
  3. Representativeness. Does the dataset look like the population you will apply the model to? This is the bias question of Section 7, and it is the one most often ignored.
  4. Documentation. Can a reader reconstruct what you did and decide whether to trust it? This is the data card of Section 9, and it is what makes the other three checkable.[21]

The published curation protocols for chemical data — Fourches, Muratov and Tropsha's "Trust, but verify" and its sequel[1][2] — address the first and fourth; this unit implements them and then adds the second and third, which are what decide whether a model built on the table will generalise.

Domain context — what can go wrong in a bioactivity record

Each record says that a compound (a small molecule) showed a certain potency against the enzyme ROCK1 in a particular assay (one experimental protocol). Five things routinely go wrong. The structure may be deposited as a salt or a different tautomer — the same molecule drawn with a hydrogen atom in a different place — so two records that should be one are two. The potency may be a censored value ("> 10 µM") because the compound was too weak to measure. Different assays measure different quantities: an IC50 depends on the experimental conditions, a Ki does not, and mixing them adds noise. The compound may be a frequent hitter or PAINS (pan-assay interference compound), a molecule that appears active in many unrelated assays because it aggregates, fluoresces or reacts rather than because it binds the target.[12] And the set of compounds in the database is not a sample of chemical space but the result of decades of optimisation campaigns, so it is dominated by a few families of close analogues — analogue bias.

2. The curation protocol as code

A protocol is only reproducible if it is code, and only auditable if every exclusion is recorded with a reason. The pattern below is worth copying into every project: a small Curator object that applies a named filter, records how many rows it removed and why, and leaves the removed rows available for inspection.

# A curation pipeline that logs every exclusion with a reason code.
class Curator:
    '''Applies named filters to a DataFrame, recording per-step counts and the excluded rows.'''
    def __init__(self, df, id_col="molecule_chembl_id"):
        self.df = df.copy(); self.id_col = id_col; self.log = []; self.excluded = {}
        self._record("E00", "raw records as delivered by the ChEMBL API", 0)

    def _record(self, code, description, n_removed, note=""):
        self.log.append(dict(step=len(self.log), code=code, description=description,
                             n_removed=n_removed, n_rows=len(self.df),
                             n_molecules=self.df[self.id_col].nunique(), note=note))

    def keep(self, code, description, mask, note=""):
        '''Keep rows where mask is True; everything else is excluded under this reason code.'''
        mask = np.asarray(mask, bool)
        dropped = self.df.loc[~mask]
        if len(dropped):
            self.excluded[code] = dropped.copy()
        self.df = self.df.loc[mask].copy()
        self._record(code, description, int((~mask).sum()), note)
        return self

    def transform(self, code, description, fn, note=""):
        '''Apply a transformation that adds columns but removes nothing.'''
        self.df = fn(self.df)
        self._record(code, description, 0, note)
        return self

    @property
    def log_frame(self):
        return pd.DataFrame(self.log)[["step", "code", "description", "n_removed", "n_rows", "n_molecules", "note"]]

# The protocol. Every keep() is one documented decision with a reason code.
normaliser, uncharger = rdMolStandardize.Normalizer(), rdMolStandardize.Uncharger()
largest = rdMolStandardize.LargestFragmentChooser()

def standardise(smiles):
    '''Canonical parent SMILES and InChIKey after normalisation, largest-fragment and uncharging.'''
    mol = Chem.MolFromSmiles(smiles) if isinstance(smiles, str) else None
    if mol is None:
        return None, None, np.nan
    try:
        mol = uncharger.uncharge(largest.choose(normaliser.normalize(mol)))
        Chem.SanitizeMol(mol)
    except Exception:
        return None, None, np.nan
    return Chem.MolToSmiles(mol), Chem.MolToInchiKey(mol), mol.GetNumHeavyAtoms()

Domain context — why structure standardisation comes before de-duplication

The same molecule can be deposited many ways: as a salt (with a counter-ion such as chloride attached by a dot in the SMILES string), as a hydrate, in a charged form, or with a functional group drawn in a non-standard but equivalent way. Standardisation applies a fixed sequence — normalise the drawing, keep the largest fragment, neutralise charges — so that all of these collapse to one canonical parent structure, which is then hashed into an InChIKey.[9][10] De-duplicating before standardising leaves the salt forms as separate compounds; in this dataset that would split ripasudil into three. Every published curation protocol therefore puts standardisation first.[1]

3. Aggregation and verification against the reference

The remaining step is the measurement-to-compound aggregation of Unit 4, now with the descriptors the modelling units need, followed by the check that matters: does our table equal the reference table the laboratory ships with the course?

# Aggregate to one row per standardised structure, then add descriptors and the Murcko scaffold.
def aggregate(g):
    exact = g.loc[~g["censored"]]
    src = exact if len(exact) else g
    return pd.Series(dict(
        std_smiles=g["std_smiles"].iloc[0],
        pref_name=next((x for x in g["pref_name"].dropna()), None),
        max_phase=g["max_phase"].max(),
        pActivity=src["pActivity"].median(),
        pActivity_min=src["pActivity"].min(), pActivity_max=src["pActivity"].max(),
        censored=bool(len(exact) == 0),
        n_measurements=len(g), n_exact=int(len(exact)),
        n_IC50=int((g["standard_type"] == "IC50").sum()), n_Ki=int((g["standard_type"] == "Ki").sum()),
        n_assays=g["assay_chembl_id"].nunique(), n_documents=g["document_chembl_id"].nunique()))

comp = (measurements.groupby("inchikey", sort=True, observed=True)
        .apply(aggregate, include_groups=False).reset_index())
comp["pActivity_range"] = comp["pActivity_max"] - comp["pActivity_min"]
comp["wide_spread"] = comp["pActivity_range"] > 1.0

def descriptors(smiles):
    mol = Chem.MolFromSmiles(smiles)
    return pd.Series(dict(
        MolWt=Descriptors.MolWt(mol), MolLogP=Crippen.MolLogP(mol), TPSA=rdMolDescriptors.CalcTPSA(mol),

        scaffold_smiles=MurckoScaffold.MurckoScaffoldSmiles(

4. How noisy is this dataset? Ask the data

Nothing in the protocol so far says how precise the surviving numbers are, and precision is the property that decides what a model can achieve. The literature answer is well known: when the same compound–target pair is measured in two different laboratories, the two values differ by something of the order of half a log unit. Kramer and colleagues established this for heterogeneous public Ki data,[3] Kalliokoski and colleagues for IC50 data pooled across sources,[4] and Landrum and Riniker revisited the question with a decade more data and reached the same conclusion.[5] We do not have to take that on trust, because our own dataset contains the replicates needed to estimate it.

The estimator is simple. For every compound measured in two different documents, take the mean pActivity reported by each document and form the difference. If each document's value is the true value plus independent noise of standard deviation σ, then each difference has standard deviation σ√2, so

$$\hat{\sigma} \;=\; \sqrt{\tfrac{1}{2}\,\overline{\Delta^2}}.$$

The restriction to different documents matters: two values from the same paper are not independent measurements, they are the same experiment reported twice.

# Estimate the experimental uncertainty from inter-document replicates of the same compound.

    out = []

        if g["document_chembl_id"].nunique() < 2:

5. The noise ceiling: what the data allow a model to achieve

The uncertainty estimate is not a curiosity; it is a budget. Write each observed value as a true value plus independent noise, y = t + ε with Var(ε) = σ². The observed variance splits as

$$\sigma_y^2 \;=\; \sigma_t^2 + \sigma^2,$$

so even a perfect model — one that returns the true value t exactly — cannot explain the σ² part. Its coefficient of determination against the observed values is capped at

$$R^2_{\max} \;=\; 1 - \frac{\sigma^2}{\sigma_y^2},$$

and its root-mean-square error cannot fall below σ. This quantity is the reliability of the measurement, and it is the number to compare a model's reported performance against — not zero, and not one.

Worked example by hand

Both calculations are small enough to do on paper, which is the best way to see that neither hides anything.

The uncertainty. Suppose one compound is reported by three documents at pActivity 7.10, 6.40 and 6.85. The three pairwise differences are |7.10 − 6.40| = 0.70, |7.10 − 6.85| = 0.25 and |6.85 − 6.40| = 0.45. Their squares are 0.4900, 0.0625 and 0.2025, whose mean is 0.7550/3 = 0.2517, so the root-mean-square difference is √0.2517 = 0.5017 and the implied per-measurement uncertainty is 0.5017/√2 = 0.355 log units. Two caveats, both important. The estimate assumes the between-document differences are pure noise, when some of them are real differences between assays — which makes σ an upper bound on the random error and the ceiling a lower bound on achievable performance. 6. The activity threshold is a modelling decision, not a fact

Most published models on data like these are classifiers, and a classifier needs classes. The potency distribution is continuous, so the classes are made by cutting it at a threshold — usually pActivity ≥ 6 (1 µM), 6.5 or 7 (100 nM) — and the threshold is chosen by convention rather than by biology. Each concentration has a specific consequence.

  • Analogue bias. When a few families dominate, a model can score well by memorising the families rather than learning chemistry, and a random train/test split hands it the answer: with a random 80/20 split of this table, 68% of test compounds have their scaffold represented in the training set. A scaffold split, which assigns whole families to one side, is the standard correction and typically drops reported performance sharply — which is the point.[16][17]
  • Source bias. When seven documents supply half the measurements, the dataset inherits seven laboratories' assay conditions, compound preferences and reporting conventions. The 54% of potency variance attributable to the assay (Unit 4) is the measurable part of this. It is the chemical analogue of the batch effect in high-throughput biology, where the processing run leaves a signature larger than the biological signal[25] and has to be removed explicitly, for instance with empirical-Bayes adjustment.[35]
  • Singleton scaffolds. The 1,453 families with one member are the compounds most unlike anything else; they are where a model's applicability domain ends (Unit 17), and they are also where a scaffold split puts most of its test set.

This is the experiment that exhibits the failure mode. A random split leaves 68% of the test compounds with a relative in the training set; a scaffold split, by construction, leaves none. The second number also shows the hidden cost: because whole families move together, the class balance of the two sides drifts apart, so a scaffold split is harder and noisier, and comparing a scaffold-split score with a random-split score from another paper is meaningless. Report which split you used, and prefer the scaffold or time split when the question is prospective.[15][19] The same failure mode in structure-based benchmarks is why decoy sets have had to be rebuilt more than once.[18]

8. Responsible data: when the rows are people

Everything so far concerned molecules, which have no rights. The moment a dataset derives from human participants the obligations change completely, and they are legal as well as ethical. This section uses the clinical metadata of a public gene-expression series — a study of gingival tissue in periodontitis, deposited in NCBI GEO[26][27] — to show what a properly minimised human dataset looks like. We inspect the schema and nothing else.

Domain context — the vocabulary of data protection

A direct identifier names a person: name, national identity number, medical-record number, e-mail. A quasi-identifier does not name anyone alone but can when combined with other quasi-identifiers or an external dataset — postcode, date of birth, sex, admission date, rare diagnosis. A sensitive attribute is the information the study is about and that the participant would not want disclosed: a diagnosis, a genotype, a behaviour. Pseudonymisation replaces direct identifiers with a code while a re-identification key is kept elsewhere; the data remain personal data in law because the link still exists. Anonymisation removes the possibility of re-identification altogether, which is much harder than it sounds and is a property of the data plus everything else in the world, not of the file. Data minimisation is the principle that you collect and keep only the fields the stated purpose requires — the single most effective protection, because a field that was never collected cannot leak.

The schema is the lesson. Eleven columns, 138 rows, 69 participants, and no age, no sex, no ethnicity, no smoking status, no date, no site of recruitment — none of the quasi-identifiers that make health data re-identifiable. patient_id is a sequential pseudonym (P001…) with no key distributed alongside the file; the only attributes present are the phenotype the study is about (diseased or healthy gingival site), the tissue, and the sampling structure. A reader can reproduce the paired analysis and cannot learn anything about a person.

That restraint has a cost — age, sex and smoking are genuine confounders for periodontitis, and their absence limits what the data can support, a limitation the depositors accepted deliberately. It also has a documented justification: re-identification attacks on health data succeed routinely when quasi-identifiers are present,[29] and with fifteen demographic attributes it is possible to re-identify almost any individual in an incomplete sample.[30]

The standard formal criterion is k-anonymity: a release is k-anonymous if every combination of quasi-identifiers appearing in it is shared by at least k records, so no record is distinguishable from fewer than k−1 others.[28] We demonstrate it on a synthetic clinical table generated in this notebook — the real GEO file has no quasi-identifiers to generalise, which is the point we just made.

Three further points, briefly, because they are the ones students most often meet first in practice.

  • k-anonymity is necessary, not sufficient. If every record in an equivalence class shares the same sensitive value, membership of the class discloses it; l-diversity requires at least l distinct sensitive values per class.[31] For analyses that release statistics rather than records, differential privacy gives a formal guarantee by adding calibrated noise to the output.[32]
  • The workflow comes before the data. Human-subjects work requires a protocol approved by an institutional ethics committee (in Chile, a Comité Ético Científico accredited by the relevant health authority) before recruitment; informed consent describing the actual secondary uses; a data-management plan saying where the data live, who may access them and when they will be destroyed; and a data-use agreement for anything shared outside the institution. The Declaration of Helsinki is the reference framework.[33] Working with an already-public, already-de-identified set such as this GEO series normally falls outside that process, but only if you do not attempt to re-identify or to link it to another source — which is itself usually a condition of the terms of use.
  • The legal frame. In the European Union the GDPR governs personal data, with pseudonymised data still in scope and anonymised data out of it. In Chile, personal-data protection became a constitutional right in 2018; the long-standing Ley 19.628 has been replaced by a modernised framework (Ley 21.719, 2024) that creates a supervisory agency and raises the standard for health data substantially, with entry into force staged. Treat the specific obligations as something to check with your institution's data-protection officer for the current year rather than from any textbook, including this one.

Domain context — metadata standards

For biological data, the community answer to "what must be recorded?" is a minimum-information standard: MIAME for microarray experiments specified the protocol, array design, normalisation and sample annotation that must accompany any deposit,[34] and its descendants cover sequencing, proteomics and imaging. These standards are why a public series such as GSE16134 can be reanalysed fifteen years later. They are the biological ancestor of the data card in the next section and of the FAIR principles[24] that govern how the course's own frozen datasets are packaged.

10. Summary

  • Quality is fitness for a stated purpose, and splits into correctness, precision, representativeness and documentation. Treat them separately; only the first is what most people mean by "cleaning".
  • Write the protocol as code with reason codes. Our pipeline excluded 44 of 5,089 records (0.9%) — 3 without a structure, 13 carrying ChEMBL's validity flag (including one impossible IC50 of exactly 0 nM), 26 with no numeric value, 2 outside the heavy-atom window — and reproduced the reference table exactly: 4,280 compounds, identical censoring flags, identical scaffolds, potencies agreeing to 0.0005 log units.
  • Estimate the noise from your own replicates. Seven hundred and eighty inter-document pairs give σ ≈ 0.51 log units, matching the published ≈0.5 for public bioactivity data; IC50 and Ki values for the same compound differ by −0.87 log units on average.
  • Convert the noise into a budget. With σ = 0.51 and an observed spread of 1.11, the reliability is 0.79: no model can exceed R² ≈ 0.79 or beat RMSE ≈ 0.51 against these labels, and a perfect classifier agrees with a noisy label only 85–87% of the time.
  • The activity threshold is a decision. Active-to-inactive goes 2.19 → 0.91 → 0.49 across 6.0 / 6.5 / 7.0; the active set narrows from 802 to 366 scaffolds; 984 compounds (36%) change class; 1,011 sit within one σ of the 6.5 cut. Report the sensitivity.
  • Diagnose the concentration. 1,453 of 2,005 scaffolds are singletons (Gini 0.47), seven of 222 documents supply half the measurements (Gini 0.82), and a random split leaves 68% of test compounds with a relative in training against 0% for a scaffold split.
  • Flag, do not silently delete. 91 PAINS alerts (2.1%) are recorded in the table; they are weaker and more often censored than the rest, so they look like substructure coincidences rather than interference.
  • When the rows are people the rules change. The GEO metadata we inspected carry no demographic quasi-identifiers at all — minimisation at collection beats generalisation afterwards — and k-anonymity, l-diversity, ethics approval, consent and the applicable data-protection law are prerequisites, not paperwork.
  • Ship a data card. Generate it from the analysis so it cannot go stale.

11. Self-assessment

1. Why must structure standardisation precede de-duplication?

Because the same molecule is deposited in several forms — free base, salt, hydrate, charged species — each with its own database identifier. De-duplicating on the identifier leaves those as separate compounds (ripasudil would appear three times in this dataset). Standardising first collapses them to one canonical parent whose InChIKey is the de-duplication key.

2. A reviewer asks why you removed 13 records. What do you show them?

The log line with its reason code (E03, "ChEMBL data_validity_comment flag"), the stored excluded rows, and the observation that twelve are potencies between 120 µM and 30 mM and one is an IC50 of exactly 0 nM whose logarithm is infinite. A curation step you cannot justify record by record is a step you should not have taken.

3. How do you estimate experimental uncertainty without repeating any experiment?

Use the replicates already in the data. For compounds measured in two different documents, take each document's mean and form the difference; if each is the truth plus independent noise of standard deviation σ, the differences have standard deviation σ√2, so σ = √(mean squared difference / 2). Here 780 pairs give σ ≈ 0.51 log units. Pairs from the same document are not independent and must be excluded.

4. Your classifier reaches 96% accuracy on a public bioactivity benchmark. What do you check first?

The split and the labels. With this dataset's noise, a perfect model agrees with the label only about 86% of the time, so 96% means either information has leaked between training and test (duplicate structures, salt forms, a random split with 68% scaffold overlap) or the test set is unrepresentative. Check de-duplication at InChIKey level first, then re-evaluate under a scaffold split.

5. What exactly is the reliability of a dataset, and why is it the right baseline?

Reliability is the fraction of the observed variance that is true signal rather than measurement noise: σ²true/σ²obs = 1 − σ²/σ²obs, here 0.79. It is the right baseline because a model is scored against noisy observations, so even a perfect predictor of the truth cannot explain the noise component. Reporting R² against 0 flatters the model; reporting it against the ceiling says how much of the available signal was captured.

6. Why report threshold sensitivity instead of choosing the best threshold?

Because the threshold creates the classes rather than discovering them: the active-to-inactive ratio moves from 2.19 to 0.49 across the three conventional cuts, and 36% of compounds change class. Choosing the threshold that maximises your metric is tuning on the outcome. Report all three, or model the continuous value.

7. What is analogue bias, and which diagnostic reveals it?

The dataset is dominated by families of close structural relatives, because it records optimisation campaigns rather than a sample of chemical space. The diagnostics are the scaffold count and its concentration — 2,005 scaffolds for 4,280 compounds, 72% singletons, Gini 0.47, largest family 214 — and the direct measurement of split leakage: 68% of a random test set has a scaffold relative in training.

8. A scaffold split lowers your reported R² by 0.2. Is the model worse?

No; the earlier number was wrong. The random split rewarded recognising known families, which is not the task. The scaffold-split number estimates performance on chemistry the model has not seen, which is what a prospective application needs. Note also that a scaffold split moves whole families and so disturbs the class balance between train and test, making the estimate noisier — report both the score and the split.

9. Should PAINS-flagged compounds be removed from a training set?

Not automatically. The filters flag substructures associated with assay interference, but they have well-documented false positives and several approved drugs match them. Flag them in the table, report the count (91 here, 2.1%), inspect them if they are influential, and state what you did. In this dataset the flagged compounds are weaker and more often censored than the rest, which is not the frequent-hitter signature.

10. Distinguish a direct identifier, a quasi-identifier and a sensitive attribute, with an example of each.

A direct identifier names the person (national identity number). A quasi-identifier identifies them only in combination or by linkage (date of birth, postcode, sex). A sensitive attribute is what the study is about and must not be disclosed (a periodontitis diagnosis, a genotype). Protection works on the quasi-identifiers: removing or generalising them is what makes the sensitive attribute safe to publish.

11. The GEO metadata we examined have no age or sex column. Is that good practice or a limitation?

Both, and the trade-off should be explicit. It removes the quasi-identifiers that drive re-identification risk, so the series can be public, but it also removes genuine confounders for periodontitis, so the data cannot support an adjusted analysis. The right response is to state the limitation in the data card rather than to wish the fields were there.

12. What belongs in a data card that does not belong in a paper's methods section?

The negative and operational information: what the dataset must not be used for, the known biases with numbers, the measured uncertainty and the performance ceiling it implies, the licence, the exclusion counts by reason code, and the version and date. A methods section describes what you did; a data card tells the next person what they can safely do.

Glossary

Analogue bias
Over-representation of families of close structural relatives, because the data record optimisation campaigns rather than a sample of chemical space.
Curation log
A per-step record of a cleaning pipeline: reason code, description, records removed, records remaining. The basis of a flow diagram and a data card.
Data card
A short structured document shipped with a dataset: purpose, provenance, composition, exclusions, known biases, recommended and discouraged uses.
Direct identifier / quasi-identifier / sensitive attribute
A field that names a person; a field that identifies them in combination or by linkage; the field the study is about and that must not be disclosed.
Gini coefficient
A measure of concentration between 0 (perfectly even) and 1 (all in one group); used here for scaffold families and source documents.
k-anonymity
A release in which every combination of quasi-identifiers is shared by at least k records, so no record is distinguishable from fewer than k−1 others.
Noise ceiling (reliability)
The fraction of observed variance that is true signal, 1 − σ²/σ²obs; the maximum R² any model can reach against those labels.
PAINS
Pan-assay interference compounds: substructures associated with apparent activity in many unrelated assays. A flag for review, not a deletion rule.
Pseudonymisation / anonymisation
Replacing identifiers with a code while a re-identification key exists (still personal data in law) versus removing the possibility of re-identification altogether.
Reason code
A short stable label attached to every excluded record, so any exclusion can be audited later.
Scaffold split
A train/test split that assigns whole Bemis–Murcko scaffold families to one side, so no test compound has a structural relative in training.
Threshold sensitivity
How class balance, composition and reported performance change when the activity cut-off is moved; a required part of any classification report on continuous data.
