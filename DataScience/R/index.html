Edición en R, equivalente unidad por unidad a la de Python: las mismas 27 unidades, los mismos datos y los mismos experimentos. Cada unidad es un notebook de Jupyter con kernel de R (.ipynb); la vista previa muestra la versión compilada con todos sus resultados y figuras. Los fingerprints moleculares vienen precalculados con RDKit, porque R no tiene un enlace a RDKit.

💡 Cómo usar Colab con R: Colab abre estos notebooks con el entorno de R, y cada notebook descarga sus datos desde este sitio la primera vez, así que necesita conexión. Si falta un paquete, instálalo con install.packages("nombre") (por ejemplo data.table, patchwork, ranger o glmnet) y luego Runtime → Run all. Para guardar tus cambios usa File → Save a copy in Drive. Los notebooks están escritos en inglés.
