1. Molecular design as search over chemical space

A computer scientist should read de novo design as a classic optimisation problem with three parts: a search space (the molecules we are allowed to propose), an objective function (a number saying how good a molecule is), and a search strategy (how we move through the space toward high objective values). What makes the molecular version hard is the search space.

Chemistry box — chemical space

Chemical space is the (imagined) set of all possible molecules, usually restricted to some size and element palette. It is the molecular analogue of the space of all strings up to length n, or all graphs on k nodes — discrete, astronomically large, and mostly full of garbage. The subset that is stable, synthesisable and drug-like is a vanishingly thin shell within it.

The numbers are the first lesson. The enumerated database GDB-17 contains every reasonable organic molecule of up to 17 heavy atoms from C, N, O, S and halogens: about 1.66 × 1011 molecules[11] — already far beyond what any screen can test. Estimates of the drug-like chemical space run from 1023 to 1060 molecules, against which the roughly 108 compounds ever synthesised and the ~2 × 109 in a purchasable catalogue such as ZINC[15] are a rounding error. The cell below makes the combinatorial explosion concrete with a toy count: how many label strings of length n exist over a small alphabet, the crudest upper bound on "molecules as strings".

If brute force and random guessing both fail, we need directed search. 2. The oracle: cheap scoring functions

The oracle is the objective function of the search: a program that takes a molecule and returns a number saying how good it is. In real projects the "true" oracle is an experiment — a binding assay, an ADMET panel, a clinical trial — which is expensive, slow and noisy. Generative methods therefore optimise a cheap surrogate oracle that can be evaluated millions of times in a loop. The art is choosing a surrogate that correlates with what you actually want without being trivially gameable (Section 9 returns to this). We use three cheap, standard oracles, all computable from structure alone.

Chemistry box — three cheap oracles

  • QED (quantitative estimate of drug-likeness, Unit 9): a single number in [0,1] combining molecular weight, logP, hydrogen-bond counts, polar surface area, rotatable bonds, aromatic rings and structural alerts into a "desirability" score.[17] Higher is more drug-like.
  • Synthetic accessibility (SA) score: an estimate from 1 (easy to make) to 10 (hard), based on the frequency of a molecule's fragments in known chemistry plus penalties for size, rings and stereocentres.[19] Lower is easier.
  • Tanimoto similarity to a target (Unit 5): the fraction of fingerprint[13] bits two molecules share, in [0,1]. Used as an oracle it drives "rediscovery" — design a molecule resembling a known active.

3. Measuring a generator: validity, uniqueness, novelty, diversity

Before we build any generator we must agree on how to grade one, because a generator that scores high on the oracle can still be useless. Four metrics, standardised by the GuacaMol[6] and MOSES[7] benchmarks, form the minimum report for any set of generated SMILES.

  • Validity — the fraction of generated strings that parse into a chemically sane molecule (RDKit returns a non-None Mol that sanitises). A SMILES generator that emits unbalanced parentheses or impossible valences wastes budget; validity measures that waste. This is the standardisation/sanitisation check of Unit 4, now applied to a model's output.
  • Uniqueness — among the valid molecules, the fraction that are distinct after canonicalisation (Unit 3). A model that repeats the same ten molecules has low uniqueness — a symptom of mode collapse.
  • Novelty — the fraction of unique valid molecules that are not in the training set. A model that memorises and regurgitates its training data has high validity and uniqueness but zero novelty, and has designed nothing.
  • Diversity — how spread out the generated molecules are in chemical space, usually the mean pairwise Tanimoto distance (1 − similarity). High diversity means the generator explores rather than clustering in one corner.

The cell implements all four on an illustrative set so the definitions become code you can reuse.

# The four generator metrics, each a few lines. Inputs: generated SMILES, training SMILES.
def canonical(s):
    m = Chem.MolFromSmiles(s)
    return None if m is None else Chem.MolToSmiles(m)

def generator_metrics(gen_smiles, train_smiles):
    valids = [canonical(s) for s in gen_smiles]
    valids = [c for c in valids if c is not None]
    validity = len(valids) / max(1, len(gen_smiles))
    uniq = set(valids)
    uniqueness = len(uniq) / max(1, len(valids))
    train_canon = {canonical(s) for s in train_smiles}
    novel = [c for c in uniq if c not in train_canon]
    novelty = len(novel) / max(1, len(uniq))
    fps = [fp(Chem.MolFromSmiles(c)) for c in uniq]
    sims = [DataStructs.TanimotoSimilarity(fps[i], fps[j])
            for i in range(len(fps)) for j in range(i+1, len(fps))]
    diversity = 1 - np.mean(sims) if sims else 0.0
    return dict(validity=validity, uniqueness=uniqueness, novelty=novelty, diversity=diversity)

demo_train = ["CCO","c1ccccc1"]
print(pd.Series(generator_metrics(demo_gen, demo_train)).round(3).to_string())

validity      0.800
uniqueness    0.875

Read the printout against the input: of the ten strings two are unparseable (so validity is 0.8), one valid molecule (ethanol) is a duplicate (so uniqueness is below 1), and two of the unique molecules (ethanol and benzene) are in the two-molecule training set (so novelty is below 1). Diversity is the mean pairwise Tanimoto distance across the unique set. These four numbers are orthogonal: a generator can ace any one while failing another, which is why all four must be reported together. A single headline number — "it reached QED 0.95" — hides a model that reached it by emitting the same invalid-adjacent string a thousand times.

Pitfall — a high oracle score is not success

It is easy to report "the generator found molecules with QED > 0.9". That claim is meaningless without validity (were they real molecules?), uniqueness (how many distinct ones?), novelty (did it just copy training data?) and synthetic accessibility (could anyone make them?). Throughout this unit, whenever we optimise an oracle we also check these guards.

4. SMILES generative models: a char-level Markov demo

The first family of molecular generators treats a molecule as its SMILES string (Unit 3)[12] and learns a language model over characters: a distribution over the next character given the characters so far. Sampling from that distribution left to right produces new strings, some of which parse into new molecules. Segler and co-workers showed that a character-level recurrent neural network (an LSTM) trained on roughly a million ChEMBL[16] SMILES learns this distribution well enough to generate mostly-valid, drug-like molecules, and that fine-tuning it on a handful of known actives biases generation toward a target — the first convincing neural de novo design.[2]

Chemistry box / CS analogy — a molecule as a sentence

A SMILES string is a sentence in a tiny formal language whose "grammar" encodes chemistry (matched ring-closure digits, balanced parentheses for branches, valence-consistent atoms). A language model learns this grammar statistically from examples, exactly as a text model learns English. The catch: unlike English, a single wrong character (an unclosed ring, an impossible valence) makes the whole "sentence" chemically invalid — which is why SMILES models must be graded on validity, and why graph-based methods (Section 5) were invented to guarantee it.

We cannot train an LSTM here (no deep-learning framework, by design). Instead we build the simplest language model that still makes the point: an order-k Markov chain over SMILES characters. It estimates the probability of the next token from the previous k tokens by counting, and samples new strings the same way. This is a few lines of NumPy and runs in milliseconds, yet it reproduces the central phenomenon — the trade-off between validity and novelty as model "memory" grows.

# Tokenise SMILES at the character level, keeping two-letter atoms (Cl, Br) as single tokens.
def tokenize(s):
    return ["^"] + re.findall(r"Cl|Br|[A-Za-z]|\d|[()\[\]=#@+\-\\/%.]", s) + ["$"]

def train_markov(smiles, order):
    table = collections.defaultdict(collections.Counter)
    for s in smiles:
        t = tokenize(s)
        for i in range(len(t) - 1):
            ctx = tuple(t[max(0, i - order + 1):i + 1])     # up to `order` preceding tokens
            table[ctx][t[i + 1]] += 1
    return table

busy = max(tbl3, key=lambda k: sum(tbl3[k].values()))          # the most frequently-seen context
print("most frequent context", busy, "-> next-token counts:", dict(tbl3[busy].most_common(4)))

# Sample new SMILES from the Markov table, backing off to shorter context when needed.
def sample_markov(table, order, rng, maxlen=60):
    out = ["^"]
    while len(out) < maxlen:
        ctx = tuple(out[-order:])
        while ctx not in table and len(ctx) > 0:
            ctx = ctx[1:]                                    # back off to a shorter context
        if ctx not in table: break
        toks = list(table[ctx]); w = np.array([table[ctx][t] for t in toks], float); w /= w.sum()
        nxt = toks[rng.choice(len(toks), p=w)]
        if nxt == "$": break
        out.append(nxt)
    return "".join(out[1:])

The interesting question is how model memory (the Markov order k) trades off against the diversity of what it produces. A longer context copies longer stretches of training strings verbatim, so validity rises but novelty falls; a shorter context mixes fragments freely, so it invents more but breaks the grammar more often. The cell sweeps k and measures both.

As the Markov order k grows, validity climbs (longer memory reproduces more of the grammar correctly) while novelty falls (the model increasingly copies whole training strings). 5. A graph-based genetic algorithm

The SMILES model of Section 4 generates by writing strings and hoping they parse. The alternative is to operate directly on the molecular graph (Units 1–2) so that every candidate is valid by construction. The classic instance is a genetic algorithm (GA) that evolves a population of molecular graphs. Jensen showed that a surprisingly simple graph GA matches or beats far more complex neural generators on standard benchmarks[4] — a humbling, important result: the method you can fully understand is also competitive.

Bridge — the GA you already know

A genetic algorithm imitates natural selection. It keeps a population of candidate solutions, scores each with a fitness function (our oracle), and builds the next generation by: selection (keep/favour the fittest), crossover (combine two parents into a child), and mutation (randomly perturb a candidate). Over generations the population drifts toward high fitness. In the AI course the candidates were bit strings or tours; here each candidate is a molecule, so crossover and mutation must produce valid molecular graphs. That is the only new idea.

5.1 Mutation and crossover on molecular graphs

A mutation makes a small local edit to one molecule: add an atom, change an element, or delete a terminal atom. Each edit can break chemistry (an impossible valence, a disconnected fragment), so every operator ends by trying to sanitise the result (Unit 4) and rejecting it if it fails — this is how the GA stays inside valid chemical space. The cell defines the three mutation operators and a sanitize guard; a real graph GA adds a few more (add a ring bond, insert or change a bond order), but these three already drive a working search.

# Mutation operators on the molecular graph. Each returns a new Mol or None; the guard enforces validity.
ORGANIC = [6, 7, 8, 9, 16, 17]                          # C N O F S Cl -- a small element palette
def free_valence(atom):
    return atom.GetTotalNumHs()                         # hydrogens a new heavy-atom bond can replace
def sanitize(mol):
    if mol is None: return None
    try:
        Chem.SanitizeMol(mol); s = Chem.MolToSmiles(mol)
        return Chem.MolFromSmiles(s) if (s and "." not in s) else None   # reject empty / disconnected
    except Exception:
        return None
def mut_add_atom(mol, rng):
    m = Chem.RWMol(mol); cand = [a.GetIdx() for a in m.GetAtoms() if free_valence(a) >= 1]
    if not cand: return None
    j = m.AddAtom(Chem.Atom(int(rng.choice(ORGANIC)))); m.AddBond(int(rng.choice(cand)), j, Chem.BondType.SINGLE)
    return m.GetMol()
def mut_change_atom(mol, rng):
    m = Chem.RWMol(mol); m.GetAtomWithIdx(int(rng.integers(m.GetNumAtoms()))).SetAtomicNum(int(rng.choice(ORGANIC)))
    return m.GetMol()
def mut_del_atom(mol, rng):
    term = [a.GetIdx() for a in mol.GetAtoms() if a.GetDegree() == 1]
    if not term: return None
    m = Chem.RWMol(mol); m.RemoveAtom(int(rng.choice(term))); return m.GetMol()
MUTATORS = [mut_add_atom, mut_change_atom, mut_del_atom]
print("defined", len(MUTATORS), "mutation operators + a validity guard")

defined 3 mutation operators + a validity guard

A crossover recombines two parents. On graphs the natural move, following Jensen,[4] is to cut each parent at a random single bond into two pieces, then join a piece of one parent to a piece of the other. We implement this with RDKit's fragment-on-bond and molzip, which welds two fragments at matching attachment points — the chemical analogue of one-point crossover on strings, where you cut two sequences and splice the halves.

# Graph crossover: cut each parent at a random acyclic single bond, splice one piece of each with molzip.
def cut_fragment(mol, rng):
    bonds = [b.GetIdx() for b in mol.GetBonds()
             if b.GetBondType() == Chem.BondType.SINGLE and not b.IsInRing()]
    if not bonds: return None
    frag = Chem.FragmentOnBonds(mol, [int(rng.choice(bonds))], addDummies=True)
    pieces = Chem.GetMolFrags(frag, asMols=True, sanitizeFrags=True)
    return pieces[int(rng.integers(len(pieces)))]
def _label_dummy(frag):
    f = Chem.RWMol(frag)
    for a in f.GetAtoms():
        if a.GetAtomicNum() == 0: a.SetAtomMapNum(1); a.SetIsotope(0)   # mark the attachment point
    return f.GetMol()
def crossover(a, b, rng):
    fa, fb = cut_fragment(a, rng), cut_fragment(b, rng)
    if fa is None or fb is None: return None
    try:
        child = Chem.molzip(Chem.CombineMols(_label_dummy(fa), _label_dummy(fb)))
        return sanitize(child)
    except Exception:
        return None

  1. Evaluate. The mean fitness of the population is (0.407 + 0.463 + 0.515 + 0.611) / 4 = 0.499; the best is benzoic acid at 0.611.

5.3 Running the genetic algorithm to convergence

Now we assemble the full loop: selection with elitism, crossover and mutation, repeated for many generations. The oracle is a constrained objective — maximise QED, but penalise molecules that are hard to synthesise (SA > 5) or outside a sensible weight window (150–500 g/mol), echoing the drug-likeness limits of Lipinski's rule of five[18]. Constraints are added as soft penalties rather than hard rejections so the search still receives a gradient of information near the boundary. We seed the population with the small, mostly-unremarkable molecules from Section 2 and let the GA improve them.

# A constrained oracle: reward QED, penalise poor synthetic accessibility and out-of-range weight.
def constrained_qed(mol):
    q = QED.qed(mol); sa = sascorer.calculateScore(mol); mw = Descriptors.MolWt(mol)
    penalty = 0.10 * max(0, sa - 5) + (0.0 if 150 <= mw <= 500 else 0.15)
    return q - penalty

def mutate(mol, rng):
    for _ in range(8):                                  # retry until an operator yields a valid molecule
        r = sanitize(MUTATORS[int(rng.integers(len(MUTATORS)))](mol, rng))
        if r is not None: return r
    return mol

# The genetic-algorithm loop: select (with elitism) -> crossover/mutate -> repeat.
def run_ga(seeds, oracle, n_gen=30, pop=60, elite_frac=0.2, p_cx=0.6, seed=0):
    rng = np.random.default_rng(seed)
    population = [Chem.MolFromSmiles(s) for s in seeds]
    best_hist, mean_hist = [], []
    for g in range(n_gen):
        ranked = sorted(population, key=oracle, reverse=True)[:pop]
        best_hist.append(oracle(ranked[0])); mean_hist.append(float(np.mean([oracle(m) for m in ranked])))
        nxt = ranked[:max(2, int(elite_frac * pop))]                 # elitism: carry the best forward
        while len(nxt) < pop:
            if rng.random() < p_cx:
                a, b = ranked[int(rng.integers(len(ranked)))], ranked[int(rng.integers(len(ranked)))]
                c = crossover(a, b, rng)
                if c is None: continue
                nxt.append(mutate(c, rng) if rng.random() < 0.3 else c)
            else:
                nxt.append(mutate(ranked[int(rng.integers(len(ranked)))], rng))
        population = nxt
    return sorted(population, key=oracle, reverse=True), np.array(best_hist), np.array(mean_hist)

6. Multi-objective optimisation and the Pareto front

Real design never has one objective. You want a molecule that is potent and drug-like and easy to make and selective — and these conflict, as the drug panel in Section 2 already showed (large potent molecules tend to be harder to make). There are two standard ways to handle several objectives.

  • Scalarisation — combine them into one number with weights, e.g. score = QED − 0.1·SA. Simple and what our constrained oracle did, but the weights are arbitrary and bake in a trade-off you may not want to commit to.
  • Pareto optimisation — keep every molecule that is not dominated by another. A molecule A dominates B if A is at least as good as B on every objective and strictly better on at least one. The non-dominated set is the Pareto front: the molecules representing the best achievable trade-offs, from which a chemist chooses.[21]

CS analogy — Pareto dominance is the skyline problem

Finding the Pareto front is exactly the "skyline" query from databases: given points in a plane, return those not beaten on both coordinates by some other point. A molecule on the front is one for which you cannot improve one objective without sacrificing another. Multi-objective GAs such as NSGA-II evolve the whole front at once; here we simply extract it from a generated population.

We take two competing objectives — maximise QED and maximise Tanimoto similarity to a target drug (here imatinib) — compute them for a population generated by the GA, and extract the Pareto front.

# Extract the Pareto front (maximising both objectives) and plot it.
def pareto_front(points):                              # points: (n,2), maximise both columns
    keep = np.ones(len(points), bool)

        if keep[i]:
            dominated = np.all(points <= p, axis=1) & np.any(points < p, axis=1)
            keep[dominated] = False
    return keep

7. Active learning: spending a costly oracle wisely

The genetic algorithm assumed the oracle is free to call. The true oracle — an experiment or an expensive simulation — is not: you can afford only a few dozen or hundred evaluations. Active learning (and its probabilistic cousin, Bayesian optimisation) is the discipline of choosing which molecules to send to the costly oracle so that each measurement teaches you the most. It is the generate–score–select loop again, but now the "select" step is where the intelligence lives.

CS analogy — active learning is a bandit over a library

You have a library of candidate molecules and a budget of k expensive labels per round. A cheap surrogate model (here a random forest on fingerprints, from Unit 13; a neural property predictor such as chemprop[27] would serve the same role) predicts the oracle value for every unlabelled candidate; an acquisition function ranks them; you label the top batch, add them to the training set, retrain, and repeat. Pure exploitation (always label the highest-predicted) is the greedy strategy; Bayesian optimisation adds an exploration bonus for candidates the surrogate is uncertain about (upper-confidence-bound, expected improvement). Such model-guided selection is now routine in machine-learning-driven drug discovery.[26]

We simulate the loop on a pool of a few hundred molecules generated by mutating the seed set, using QED as a stand-in for the (here, artificially cheap) "true" oracle so we can measure success. We compare greedy active learning against random selection by counting how many of the pool's top-decile molecules each strategy has discovered after each round.

# One active-learning loop: surrogate RF -> acquire top-batch -> label -> retrain. Greedy vs random.
def active_learning(strategy, rounds=6, init=8, batch=12, seed=0):
    r = np.random.default_rng(seed); n = len(y)
    labeled = list(r.choice(n, init, replace=False))
    hits = [int((y[labeled] >= thr).sum())]
    for _ in range(rounds):
        lab = set(labeled); unlabeled = [i for i in range(n) if i not in lab]
        if strategy == "random":
            pick = list(r.choice(unlabeled, batch, replace=False))
        else:                                            # greedy: label the highest-predicted candidates
            rf = RandomForestRegressor(n_estimators=120, random_state=seed).fit(X[labeled], y[labeled])
            pred = rf.predict(X[unlabeled]); pick = [unlabeled[k] for k in np.argsort(pred)[-batch:]]
        labeled += pick; hits.append(int((y[labeled] >= thr).sum()))
    return np.array(hits)

8. Benchmarks: how the field measures progress

A method is only as credible as the benchmark it is tested on, and generative chemistry learned this the hard way: early papers each reported their own metrics on their own datasets, so nothing could be compared. Two community benchmark suites fixed this.

  • GuacaMol[6] defines two families of tasks on a ChEMBL-derived dataset. Distribution-learning tasks ask whether a model reproduces the statistics of the training set — measured by validity, uniqueness, novelty and the Fréchet ChemNet Distance (below). Goal-directed tasks ask a model to maximise a battery of scoring functions (rediscovery of a known drug, similarity, isomer matching, multi-property objectives) — exactly the optimisation our GA performs. Crucially, the GuacaMol paper showed that a simple graph genetic algorithm is a very strong goal-directed baseline,[6] which is why this unit builds one.
  • MOSES[7] (Molecular Sets) standardises a cleaned dataset, a train/test split and a battery of distribution-learning metrics — validity, uniqueness, novelty, internal diversity, fragment and scaffold similarity, and the Fréchet ChemNet Distance — with reference implementations and leaderboard baselines (char-RNN,[2] VAE,[3] adversarial autoencoder, latent GAN).

Chemistry/CS box — the Fréchet ChemNet Distance (FCD)

FCD[8] is the molecular analogue of the Fréchet Inception Distance used to score image generators. It passes both the generated set and a reference set through a fixed neural network trained on chemistry, fits a Gaussian to each set's activations, and reports the distance between the two Gaussians. Low FCD means "the generated molecules look like the reference set in a learned feature space" — a single number capturing distributional realism that the four basic metrics miss. We only describe it (it needs a pretrained network, which is outside this unit's no-deep-learning scope).

9. What goes wrong: oracle hacking and unsynthesisable molecules

A generative method is an optimiser, and an optimiser will exploit every weakness of its objective. This is Goodhart's law in molecular form: when a cheap oracle becomes the target, it stops being a good measure. Two failure modes dominate, and both are easy to reproduce.

The first is oracle hacking: the search finds molecules that score well on the surrogate but are chemically absurd, because the surrogate was never meant to be optimised to its extreme. The clearest example is a trivially gameable oracle — raw lipophilicity (logP), with no size or synthesisability guardrails. Because every extra greasy fragment raises logP and nothing penalises growth, the GA drives the score to absurdity by simply stapling fragments together into an enormous, un-drug-like molecule. The cell optimises raw logP for only eight generations and contrasts the result with the constrained winner from Section 5.

The lesson is general: a generative model is only as good as its oracle, and single cheap objectives are almost always gameable — the reason community benchmarks score many properties at once.[6]

The second failure mode is unsynthesisable output: even without pathological bonding, generators routinely propose molecules that are perfectly valid graphs but that no one can actually make, or that contain reactive, unstable or toxic groups. A systematic study found that a large fraction of molecules from several generative models score poorly on synthesisability and would be impractical to pursue.[20] This is why synthetic accessibility (Unit 17's retrosynthesis ideas, the SA score here) belongs in the objective, not as an afterthought, and why the field increasingly couples generators to retrosynthesis planners.

Pitfalls to carry forward

  • Report all metrics, not the headline. A high oracle score with low validity, novelty or synthesisability is a non-result. GuacaMol and MOSES exist precisely to prevent cherry-picking.[6]
  • Guard the oracle. Add synthesisability, validity-of-chemistry and property constraints; prefer multi-objective Pareto optimisation to a single scalarised number.[24]
  • A valid graph is not a molecule you can buy. Treat generated structures as hypotheses to be triaged by synthesisability and expert review,[28] then validated experimentally — the only oracle that ultimately counts.
  • Beware distribution shift and hype. A model optimised on a cheap oracle may wander outside its applicability domain (Unit 14); striking single successes[25] and adversarially-trained generators[29] are promising but not yet routine, and de novo design remains an assistive tool, not an autopilot.[1]

11. Self-assessment

1. Why can you not simply enumerate all drug-like molecules and score each one?Drug-like chemical space is estimated at 1023–1060 molecules; even the enumerated GDB-17 (up to 17 heavy atoms) already has ~1.7×1011. No computer can store or score a meaningful fraction, so design must be a directed search, not enumeration.
2. A generator reports oracle score 0.95 on QED. What four further numbers do you demand before believing it designed anything useful?Validity (did the outputs parse to real molecules?), uniqueness (how many distinct molecules?), novelty (were they absent from the training set, or just memorised?), and synthetic accessibility (could they be made?). A high score with poor values on any of these is a non-result.
3. In the char-level Markov demo, increasing the order raised validity but lowered novelty. Explain both effects.A longer context reproduces more of the local SMILES grammar correctly, so fewer strings are invalid (validity up). But a longer context also increasingly copies whole substrings from the training set, so more generated molecules duplicate training molecules (novelty down). It is a memory-vs-exploration trade-off.
4. What is the one chemical idea that distinguishes a molecular genetic algorithm from a generic one on bit strings?The crossover and mutation operators must produce valid molecular graphs. Each edit is followed by a sanitisation step (Unit 4) that rejects impossible valences or disconnected fragments, keeping the population inside valid chemical space. Everything else is the standard GA.
5. In the hand-traced generation, the best fitness stayed at 0.611 while the mean rose from 0.499 to 0.558. Which GA mechanism guarantees the first, and which drives the second?Elitism (copying the top individuals unchanged) guarantees the best never decreases. Selection plus variation (crossover and mutation applied to the fitter parents) raises the mean by replacing poor individuals with offspring near the good ones.
6. Define Pareto dominance, and state what the Pareto front contains.Molecule A dominates B if A is at least as good as B on every objective and strictly better on at least one. The Pareto front is the set of non-dominated molecules — the best achievable trade-offs, from which no objective can be improved without worsening another.
7. Why is scalarising several objectives into one weighted sum sometimes the wrong choice?The weights fix a trade-off in advance and arbitrarily; a weighted sum can also miss points on non-convex parts of the Pareto front. Keeping the whole front lets a chemist choose the trade-off afterwards, informed by priorities no weight vector captured.
8. In the active-learning demo, both strategies spent the same oracle budget, yet active learning found far more good molecules. What did the surrogate model buy you?It predicts the oracle value of unlabelled candidates, so the acquisition step spends each expensive label on a molecule likely to be good rather than on a random one. The budget is the same; the information per label is much higher.
9. What is the Fréchet ChemNet Distance, and what does it capture that validity/uniqueness/novelty do not?FCD passes generated and reference molecules through a fixed chemistry-trained network, fits a Gaussian to each set's activations, and measures the distance between them. It captures distributional realism — whether the generated set resembles real molecules in a learned feature space — which the per-molecule counting metrics miss.
10. You optimise raw QED and obtain a molecule with QED 0.9 but SA score 8. What happened, and how do you fix it?Oracle hacking: the optimiser exploited a cheap objective to its extreme, producing a high-QED but unsynthesisable molecule. Fix it by adding a synthetic-accessibility penalty and validity/weight constraints to the objective, or by optimising QED and SA as a multi-objective Pareto problem.
11. Why is a chemically valid generated graph still only a hypothesis?Validity guarantees the graph obeys valence rules, not that the molecule is stable, non-toxic, synthesisable, or active against a target. Generated structures must be triaged by synthesisability and expert review, then tested experimentally — the only decisive oracle.
12. The GuacaMol paper found a simple graph GA to be a top goal-directed baseline. What practical lesson should you draw before reaching for a deep generative model?Always run a strong, cheap, interpretable baseline first. If a graph GA already saturates your oracle, a large neural model adds cost and opacity without benefit. Deep models earn their keep only when they measurably beat such baselines on an honest benchmark.

Glossary

Acquisition function
In active learning / Bayesian optimisation, the rule that ranks unlabelled candidates for the next oracle batch (e.g. greedy exploitation, upper-confidence-bound).
Active learning
Iteratively choosing which candidates to send to a costly oracle so each measurement is maximally informative; a surrogate model guides the choice.
Chemical space
The set of all possible molecules (usually within some size/element limits); astronomically large and mostly chemically useless.
Crossover
A genetic-algorithm operator that recombines two parent molecules into a child; on graphs, by cutting each parent at a bond and splicing pieces.
De novo design
Designing new molecules from scratch to meet a target property, rather than selecting from an existing library.
Diversity
How spread out a set of molecules is in chemical space, often the mean pairwise Tanimoto distance.
Elitism
Copying the fittest individuals unchanged into the next generation so the best solution is never lost.
Fréchet ChemNet Distance (FCD)
A distributional metric comparing generated and reference molecules in a neural feature space; lower is more realistic.
Genetic algorithm (GA)
A population-based optimiser using selection, crossover and mutation to evolve candidates toward high fitness.
Mutation
A genetic-algorithm operator making a small random edit to one molecule (here: add an atom, change an element, or delete a terminal atom).
Novelty
The fraction of generated unique valid molecules not present in the training set.
Oracle
The scoring function a generative search optimises; cheap surrogates (QED, SA, similarity) stand in for an expensive true oracle (an assay).
Oracle hacking
When an optimiser exploits weaknesses of a cheap oracle to score well with chemically useless molecules (Goodhart's law).
Pareto front
The set of non-dominated candidates under several objectives; the best achievable trade-offs.
QED
Quantitative estimate of drug-likeness: a [0,1] desirability score combining physicochemical properties (Unit 9).
SA score
Synthetic-accessibility score (1 easy – 10 hard), estimating how difficult a molecule is to synthesise.
Scalarisation
Combining several objectives into one number via weights; simple but commits to a fixed trade-off.
Surrogate model
A cheap predictive model (here a random forest on fingerprints) approximating a costly oracle to guide search.
Uniqueness
The fraction of valid generated molecules that are distinct after canonicalisation; low uniqueness signals mode collapse.
Validity
The fraction of generated strings/graphs that parse into a chemically sane molecule.
